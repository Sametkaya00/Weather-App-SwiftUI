# Weather App

## Keywords:

- SwiftUI
- MVVM
- OpenWeather
- API Request

## Main Features:

### Home Page
Displays the current weather information, wind speed, humidity, and sunrise/sunset times for the user's location.

### Search Page
Allows the user to search for any city or country to view its weather information.
